# Runbooks

One file per alert, named after the alert. Each runbook answers:

1. **What does this alert mean?** (user/fleet impact)
2. **How do I confirm it?** (queries, commands)
3. **How do I mitigate it?** (step by step, safest first)
4. **How do I escalate?**
